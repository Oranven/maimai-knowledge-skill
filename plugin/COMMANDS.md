# 指令目录

插件 `astrbot_plugin_maimai_kb` v1.5.0 的全部聊天指令。所有指令只在**聊天里**发，不需要面板或命令行。

- **前缀**：`舞萌`，也可用 `maimai` / `mai` / `查歌`；前面带 `/` `!` `！` `。` `.` 也能识别（`/舞萌 13+`）
- **分隔符**：参数之间用 `|`（半角竖线），全角空格、多余空格都会被清掉
- **权限**：标「所有人」的谁都能用；标「管理员」的需要 `admin_qq` 白名单里的号，或平台判定的管理员（`event.is_admin()`）
- **手动录入总开关**：配置项 `manual_enabled` 关掉后，所有写入指令都返回「功能已关闭」

---

## 一、查询（所有人）

| 指令 | 作用 | 示例 |
| --- | --- | --- |
| `舞萌 <曲名或别名>` | 详情：标准 / DX 谱面、显示等级、精确定数、谱师、别名 | `舞萌 Oshama Scramble!` |
| `舞萌 查询\|查\|查歌\|搜\|搜索\|详情\|谱面 <曲名>` | 同上，显式表达「我要查歌」 | `舞萌 详情 牛乳` |
| `舞萌 定数\|ds\|常数\|拟合 <曲名> [难度]` | 只列定数行，不显示别名和谱师 | `舞萌 定数 Oshama Scramble! 紫` |
| `舞萌 <等级>` | 按显示等级查谱面，按定数降序 | `舞萌 13+` |
| `舞萌 等级\|level\|lv\|标级 <等级>` | 同上，显式写法 | `舞萌 等级 14` |
| `舞萌 定数 <下限>-<上限>` | 按定数区间筛选 | `舞萌 定数 13.5-13.9` |
| `舞萌 统计\|stats\|状态\|快照` | 数据快照：版本、歌曲/谱面数、来源 | `舞萌 统计` |
| `舞萌 帮助\|help\|说明\|?\|？` | 打印用法；直接发 `舞萌` 也是帮助 | `舞萌 帮助` |

定数区间的分隔符认 `-`、`~`、`～`、`至`：`13.5-13.9`、`13.5~13.9`、`13.5至13.9` 等价，先后写反会自动交换。

## 二、筛选词（跟在查询尾部）

可以加在任何查询后面，类型各一个、难度各一个，顺序随意：

| 类别 | 可用写法 | 效果 |
| --- | --- | --- |
| 谱面类型 | `standard` `std` `sd` `标准` `旧` `旧谱` `旧曲` | 只看标准谱面 |
| 谱面类型 | `dx` `新` `新谱` `新曲` | 只看 DX 谱面 |
| 难度 | `basic` `bas` `绿` `绿谱` | BASIC |
| 难度 | `advanced` `adv` `黄` `黄谱` | ADVANCED |
| 难度 | `expert` `exp` `红` `红谱` | EXPERT |
| 难度 | `master` `mas` `紫` `紫谱` | MASTER |
| 难度 | `remaster` `remas` `re` `白` `白谱` | Re:MASTER |

```text
舞萌 14 dx master              Lv.14 里 DX MASTER 的谱面
舞萌 定数 14.8-15.0 dx master  DX MASTER 且定数 14.8~15.0
舞萌 牛乳 紫                   牛乳（别名）的 MASTER 谱面
舞萌 13+ 标准                   标准谱面里 Lv.13+ 的
```

## 三、手动录入与官方曲目修正（管理员）

手动条目、官方谱面补丁和官方别名补丁都写在插件数据目录，不写回官方快照，版本更新/覆盖安装都不会丢。

| 指令 | 别名写法 | 说明 |
| --- | --- | --- |
| `舞萌 添加歌曲 曲名 \| 艺术家 [\| 分类] [\| 版本] [\| 别名] [\| dx/标准]` | `录歌` `加歌` `新增歌曲` | 建档。只发 `舞萌 添加歌曲`（不带参数）进入引导。第 5 段别名用逗号/顿号分隔；第 6 段填 `dx`/`标准` 表示这些别名只属于那类谱面 |
| `舞萌 加谱面 曲名 \| [类型] 难度 等级 [定数]` | `添加谱面` `改谱面` | 补/改一张谱面；手动库里没有这首歌时会自动去官方快照找并打「谱面补丁」；写 `标准` 就是标准谱面，不写默认 `dx`；同曲可同时有两种类型 |
| `舞萌 改谱面信息 曲名 \| [类型] 难度 \| 谱师=... \| 标签=... \| 音符=...` | `谱面信息` `改属性` | 改官方谱面的谱师 / 标签 / 音符数（不动等级、定数）；不写字段就是查看当前值 |
| `舞萌 加别名 曲名 \| 别名1, 别名2 [\| dx/标准]` | `添加别名` `别名+` | 追加别名；末段 `dx`/`标准` = 该类型专属别名，不填 = 通用别名。**官方快照里的歌同样可用**；对已有别名再发一次带类型，就是改它的归属 |
| `舞萌 删除别名 曲名 \| 别名 [\| dx/标准]` | `删别名` | 删别名；带类型就只在该类型别名里找，不会误删另一类。官方自带别名也能隐藏，再加回来即恢复 |
| `舞萌 删除歌曲 曲名` | `删歌` | 删除整条手动条目 |
| `舞萌 删除谱面 曲名 \| [类型] 难度` | `删谱面` | 删除手动谱面；官方曲目则撤销该张谱面补丁，恢复官方数据 |
| `舞萌 手动列表` | `手动库` `手动歌曲` | 列出手动库条目、谱面、别名数、录入人，以及官方曲目的谱面补丁和别名修正 |

### 3.1 一条命令写完

```text
舞萌 添加歌曲 千本樱 | 黒うさP | 流行&动漫 | 手动录入 | 葱歌、千本桜 | dx
```

- 分类、版本可空（直接留空段或省略），缺的段落补默认值「舞萌 / 手动录入」
- 只给曲名、没给艺术家 → 进入引导，按提示重发「曲名 \| 艺术家」（艺术家写「未知」也可以）
- 别名不能等于另一首歌的曲名（会串台，直接拒绝）；最多 20 个/首
- 定数必须和显示等级自洽：`紫 14 14.9` 会被拒绝并提示 14.9 对应 14+；不填定数就存空，显示 `—`，不会猜

### 3.2 引导流程

发 `舞萌 添加歌曲`（或 `录歌` / `加歌` / `新增歌曲`）后进入引导，之后**不用带前缀**直接发内容：

```text
> 舞萌 添加歌曲
🎙 手动录歌开始。
请发一条：曲名 | 艺术家 | 分类(可空) | 版本(可空) | 别名(可空) | 别名归属(可空)
例如：千本樱 | 黒うさP | 流行&动漫 | 手动录入 | 葱歌、千本桜
别名归属填 dx 或 标准，表示这些别名只对那类谱面生效；不填就是通用别名。
随时发「取消」退出。

> 千本樱 | 黒うさP | 流行&动漫 | 手动录入 | 葱歌、千本桜
已建档「千本樱」（黒うさP｜流行&动漫｜手动录入），接着加谱面：难度 等级 定数
接着发谱面：难度 等级 定数，一行一张，如「紫 14+ 14.9」；发「完成」结束。

> 标准 紫 14 14.2          ← 标准谱面
「千本樱」已写入 标准 MASTER Lv.14

> 紫 14+ 14.9              ← DX 谱面
「千本樱」已写入 DX MASTER Lv.14+

> 别名 追加别名, 第三个别名   ← 通用别名
「千本樱」已加别名：追加别名、第三个别名（共 4 个）

> 别名 千本樱标准名 标准      ← 标准谱面专属别名
「千本樱」已加别名（标准谱面专属）：千本樱标准名（共 5 个）

> 完成
✅ 「千本樱」已保存，共 2 张谱面。
```

| 引导中可发 | 效果 |
| --- | --- |
| `难度 等级 定数`（如 `紫 14+ 14.9`） | 写一张 DX 谱面 |
| `标准 难度 等级 定数`（如 `标准 红 12 12.2`） | 写一张标准谱面 |
| `别名 xxx, yyy` | 加通用别名 |
| `别名 xxx dx` / `别名 xxx 标准` | 加该类型专属别名 |
| `完成` `结束` `好了` `没了` `保存` `done` `ok` | 保存并退出 |
| `取消` `退出` `算了` `不录了` `cancel` | 退出（已建档的条目不删） |

引导 300 秒无输入自动失效（`manual_session_ttl` 可调），失效后再发内容不会误写；发带「舞萌」的指令会正常走指令，不会当作引导输入。

### 3.3 给官方快照已有的歌补 / 改谱面

官方快照里已经有的歌，**不用重新建档**，直接 `加谱面` 就行：插件会自动在官方库里按曲名（或别名）精确匹配，把这张谱面写成 `manual_charts.json` 里的「补丁」，只覆盖/追加那一张，官方 `songs.json` 一个字节都不动。

```text
> 舞萌 加谱面 Oshama Scramble! | dx | 白 | 15 | 15.0
已给官方条目「Oshama Scramble!」补上 DX Re:MASTER：Lv.15（定数 15.0）。撤销用「舞萌 删除谱面 Oshama Scramble! | dx remaster」
官方快照文件不动，查询里这张谱面带 📝 手动修正。

> 舞萌 Oshama Scramble!
DX 谱面（#10363）
  MASTER    Lv.13+ 定数 13.6｜谱师 Jack｜底力谱 体力谱 绝赞段 …
  Re:MASTER Lv.15  定数 15.0　📝 手动修正
──────────────
📝 手动修正 1 张谱面｜by 你的昵称 · 更新 2026-11-05
撤销：舞萌 删除谱面 曲名 | 类型 难度（如 dx 白）

> 舞萌 15 dx remaster
📈 Lv.15（DX Re:MASTER） 共 2 张
 1. Oshama Scramble! · DX Re:MASTER · 15.0 📝
 2. 系ぎて · DX Re:MASTER · 15.0

> 舞萌 删除谱面 Oshama Scramble! | dx 白
已撤销「Oshama Scramble!」DX Re:MASTER 的手动修正，恢复官方数据。
```

要点：

- **两种用途**：官方缺这张谱面 → 补上；官方谱面定数/等级不对 → 覆盖修正（同样一张一套，重复写就是更新）
- **任意一张都能改**：标准 / DX 两类 × 绿/黄/红/紫/白 五个难度，逐张独立覆盖；原有谱面和缺失谱面都走同一条指令
- **同名曲**：官方库里有同名曲时用 `曲名@艺术家` 指定，例如 `舞萌 加谱面 Oshama Scramble!@t+pazolite | dx 白 15 15.0`
- **校验一样严**：定数必须和显示等级自洽（`紫 14 14.9` 会被拒绝），不填定数显示 `—`
- **进入所有检索**：补丁谱面会出现在 `舞萌 <曲名>`、`舞萌 15 dx remaster`、`舞萌 定数 14.8-15.0`、AI 注入里，行尾带 📝
- **可撤销**：`舞萌 删除谱面 曲名 | 类型 难度` 删掉补丁就恢复官方数据；官方谱面本身不能删，只能补丁覆盖
- **不写官方文件**：补丁存在 `manual_charts.json`，`update_all.py` 刷新快照、覆盖安装新 zip 都不会丢

### 3.4 改谱面的谱师 / 标签 / 音符数

等级和定数用 `加谱面` 改；谱师、标签、音符数用 `改谱面信息` 改，互不覆盖：

```text
> 舞萌 改谱面信息 Oshama Scramble! | dx 紫 | 谱师=Jack | 标签=底力谱,体力谱 | 音符=1234
已给官方条目「Oshama Scramble!」补上 DX MASTER：Lv.13+（定数 13.6）。撤销用「舞萌 删除谱面 Oshama Scramble! | dx master」

> 舞萌 改谱面信息 Oshama Scramble! | dx 紫
🎼 Oshama Scramble! · DX MASTER
谱师｜Jack
标签｜底力谱、体力谱
音符｜1234（total 1234）
```

要点：

- **字段可任选**：`谱师=`、`标签=`、`音符=` 写几个改几个；不写字段就是查看当前值
- **音符两种写法**：总数 `音符=1234`，或五个数 `音符=72,8,7,8,3`（tap、hold、slide、touch、break），也认 `tap=72,hold=8,...`
- **只改等级/定数不会丢字段**：`加谱面` 覆盖等级/定数时，原有谱师、音符数、标签会保留
- **只对官方曲目**：写入 `manual_charts.json` 的同一张谱面补丁；`舞萌 删除谱面 曲名 | dx 紫` 撤销后全部恢复官方值

### 3.5 给官方快照已有的歌改别名（含标准 / DX 分归属）

官方曲目的别名也能直接在聊天里改，同样不写 `songs.json`，而是存进 `official_aliases.json`：

```text
> 舞萌 加别名 Oshama Scramble! | 官方新别名
「Oshama Scramble!」已加别名：官方新别名（共 31 个）
官方快照文件不动，查询里会带上 📝 别名修正。

> 舞萌 加别名 Oshama Scramble! | 官方DX名 | dx
「Oshama Scramble!」已加别名（DX 谱面专属）：官方DX名（共 32 个）
```

用这个别名查询时只显示 DX 谱面：

```text
> 舞萌 官方DX名
🎵 Oshama Scramble!
...
DX 谱面（#10363）
  MASTER    Lv.13+ 定数 13.6｜谱师 Jack｜底力谱 体力谱 绝赞段 …

别名（DX 谱面）｜官方DX名
ℹ️「官方DX名」是 DX 谱面专属别名，只显示了 DX 谱面；看另一类型就发「舞萌 官方DX名 标准」。
```

官方自带的别名也能改归属，或改成通用别名：

```text
> 舞萌 加别名 Oshama Scramble! | 标奶 | 标准
「Oshama Scramble!」已把 标奶 改为标准谱面专属（共 30 个）

> 舞萌 加别名 Oshama Scramble! | 标奶
「Oshama Scramble!」已把 标奶 改为通用别名（共 30 个）
```

要点：

- **三种归属**：通用 / 标准谱面专属 / DX 谱面专属；类型专属别名查询会自动只显示该类型谱面，并给 ℹ️ 提示
- **改已有别名**：对官方自带别名再发一次「加别名 + 类型」即可改归属；不带类型 = 改回通用
- **删除**：`舞萌 删除别名 曲名 | 别名` 可隐藏官方自带别名；`... | dx` 只在该类型别名里找，防止误删另一类
- **可恢复**：删掉的官方别名再用 `加别名` 加回来即可；每次改动都会在详情底部显示 `📝 别名修正 N 条`
- **同名曲**：用 `曲名@艺术家` 定位，例如 `舞萌 加别名 Link@Clean Tears | 某别名`

## 五、权限开关

| 配置项 | 默认 | 作用 |
| --- | --- | --- |
| `manual_enabled` | true | 关掉后所有手动写入指令失效 |
| `user_submit` | true | 普通用户能否 `提交` |
| `admin_qq` | 空 | 管理员 QQ 白名单，逗号/顿号/空格分隔 |
| `allow_all_edit` | false | 放开给所有人写（仅调试用） |
| `manual_dir` | 空 | 手动库目录，空 = `<AstrBot>/data/plugin_data/astrbot_plugin_maimai_kb/` |
| `manual_max` | 200 | 手动库最多多少首 |
| `manual_session_ttl` | 300 | 引导流程超时秒数 |

## 六、常见回复与处理

| 回复 | 原因 / 处理 |
| --- | --- |
| `没有找到「X」对应的歌曲` | 曲名/别名未命中，试试官方别名或短词；也可手动建档 |
| `手动库里没有「X」` | 手动词条不存在，先 `舞萌 添加歌曲` |
| 定数不一致提示（如 `14.9 对应 14+`） | 显示等级与定数不符，改等级或改定数 |
| 别名冲突（`是另一首歌的曲名`） | 换一个别名，避免查询串台 |
| `该类型没有谱面` | 筛选的类型下这首歌没谱面，删掉 `dx`/`标准` 再看 |
| `官方谱面本身不能删，只能加补丁覆盖` | `删除谱面` 对官方谱面无效；要改定数就发 `加谱面` 覆盖 |
| `没看懂难度` | 难度只认 绿/黄/红/紫/白 或 bas/adv/exp/mas/re |
| `功能已关闭` / `只允许管理员操作` | 配置或权限限制；普通用户改走 `提交` |
| 别名查询只显示一类谱面（带 ℹ️ 提示） | 命中的是「标准/DX 专属别名」，属于预期行为；发 `舞萌 <别名> 标准` 或 `dx` 切类型 |

## 八、AI 侧（不是指令）

- LLM 工具 `maimai_lookup(query, kind)`：`kind` 取 `auto` / `song` / `ds` / `level` / `stats`
- 对话里提到曲名（含别名）时，自动把定数摘要注入 `system_prompt`（`inject_enabled` 可关）
